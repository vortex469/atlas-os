# v0.65 P2 — bounded durable control-plane evidence

P2 adds one explicitly constructed, default-off Core service and SQLite store
for the P1 reference-only decision. It records an accepted decision as evidence;
it cannot approve, admit, activate, contact, replay, or start anything.

The store is owner-scoped and append-only. Each owner has at most 16 records and
the store has at most 256 records; serialized records are bounded. A durable
reservation is created before the evidence append. Owner-plus-idempotency-key
duplicates return the existing record, conflicting requests are refused, and a
reserved subject is never reused. An interrupted append is indeterminate and
cannot be retried as a replay. SQLite integrity, application identity, canonical
model serialization, ownership, and fingerprints are checked on every restart.

The service requires authenticated owner identity, verified permission, exact
configured lineage/policy fingerprints, and the exact predecessor fingerprint.
Expired, ambiguous, authority-bearing, foreign, malformed, or widened evidence
is refused. Reads require the same owner and never invoke a reader or effect
adapter. `enabled=False` is the default and is required for production
construction until a separately authorized release changes that boundary.
