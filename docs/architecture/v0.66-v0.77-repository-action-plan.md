integrated changes. Commit each implementation with its own completion record;
do not assign version numbers retroactively to already completed unrelated
work. Local implementation completion is distinct from release acceptance,
remote exact-SHA CI and publication. Keep runtime/model/helper limitations

separately before claiming production readiness or progressing toward v1.
