# v0.65 P1 — closed control-plane contract

P1 adds only a Core-owned, reference-only value contract at
`services/atlas-core/app/control_plane/contract.py`. It is pure: all facts,
lineage pins, policy fingerprints, and evaluation time are injected. It does
not read a clock, contact a service, persist state, create a runtime, or emit
an operational request.

The models are frozen and closed (`extra="forbid"`), use strict scalar types,
copy nested inputs, canonical domain-separated SHA-256 fingerprints, and
fixed false authority fields. Evaluation has exactly two outcomes. Invalid,
foreign, stale, widened, ambiguous, expired, or authority-bearing input is
redacted to a deterministic blocked result; accepted means only that the
reference was recorded as evidence. It never means approval, admission,
activation, execution, or permission to contact an effect plane.

The contract deliberately has no route, store, consumer, credential,
endpoint, command, payload, retry, or effect. P1 tests exercise unknown-field
rejection, policy widening, foreign lineage, expiry, authority payloads,
determinism, and mutable-input isolation. The retained v0.64 boundary tests
remain required and unchanged.
