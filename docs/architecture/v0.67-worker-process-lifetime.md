# v0.67 — bounded worker process lifetime

Status: implementation complete locally; unreleased. The operator selected
completion through v0.70. This closes the prior v0.67 draft against its selected
acceptance criteria, without deployment, runtime enablement or publication.

The worker starts each model command in a new session. It kills that owned
process group before returning or deleting the disposable workspace, including
when the direct parent exits but a child keeps an output pipe open. A timeout
produces the existing `timeout` failure, no collected patch and no changed-file
approval. There is no resubmission or local fallback.

Acceptance: 59 worker tests passed. Three real-subprocess tests cover a live
parent/child timeout, an exited parent with an inherited output pipe, and a
successful parent leaving a background child with closed output pipes. The
worker fixture also edits a disposable clone before sleeping: timeout discards
that edit, removes the workspace and leaves the source repository unchanged.
No real model or account credentials are used in these tests.

The process-group boundary covers inherited children. A process deliberately
escaping into another session is not claimed to be contained by process-group
signals; the outer sandbox/container remains required. Output buffering is
unchanged here and is the separate v0.68 milestone.
