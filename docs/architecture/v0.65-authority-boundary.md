# v0.65 corrective authority boundary

Status: **Deferred. P1–P5 successor implementation removed.** The v0.65 P0
decision and Sync are authoritative: the repository did not prove a distinct,
trusted control-plane activation decision, so no successor contract, store,
service, route, permission, consumer, or UI was selected.

## Decision

Reconcile the deferred decision by removing the implementation introduced by
the P1–P5 commits. The P0 analysis remains valid evidence and is not converted
into a successor contract. The v0.64 runtime-definition evidence remains
reference-only; it is not activation authorization.

The retained boundary is Core-owned evidence with `evidence_only=true`,
`reference_only=true`, `payload_bytes=0`, all 67 fixed-false authority/material
fields, and all seven unresolved blockers. Mission Control remains GET-only and
read-only. Agent, the execution worker, operational workflows, deployment
surfaces, and effect-plane adapters have zero v0.65 consumers.

## Removed successor surfaces

The corrective change removes the v0.65 control-plane package, SQLite
store/service, Core API route and discovery entry, operator permissions,
configuration, startup wiring, and related implementation tests. The P1/P2
records are retained only as historical evidence of what was removed; they do
not describe supported repository behavior.

No runtime contact, queue claim/lease/ack/consume/requeue, activation, worker
start, Agent invocation, execution, installation, deployment, rollback,
publication, retry/resend, repair, replay, or operational authority is added.

## Open gates

Trusted author/provenance, a distinct consumer decision, exact approval and
immutable subject/policy inputs, authenticated effect-plane contact,
expiry/cancellation/ownership semantics, one-shot uncertainty recovery,
measurable limits, and repository-wide no-authority-promotion proof remain
open. A future successor requires a new normative decision and exact evidence
for every gate; no schema or hash/UUID domain is reserved here.
