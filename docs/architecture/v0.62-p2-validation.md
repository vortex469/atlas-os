# v0.62 P2 — retained bounded durable append-only evidence

The v0.62 authority freeze retains the existing Core-owned v0.57 reader,
service, and bounded SQLite journal. The requested durable append-only behavior
therefore adds no successor schema, marker, route, consumer, migration, or
runtime authority.

`test_v062_durable_evidence.py` provides v0.62 regression evidence for the
retained implementation:

- successful records, audited append failures, and interrupted reservations
  remain permanent across restart;
- duplicates do not reread prerequisites or replay a reserved subject;
- a retained reservation consumes the configured global capacity; and
- changing the retained application identifier to `62` fails closed without
  migration or mutation of the damaged journal.
