# Atlas v0.3 Development Line

The v0.3 line introduced the first Atlas intelligence and reusable
knowledge-assessment foundations.

- Added the Atlas Intelligence Engine.
- Added the intelligence summary API.

- Added reusable application and database assessment foundations.

These are historical development releases. The current repository is in
the Foundry active-development phase; see
