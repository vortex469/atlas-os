# Atlas OS

Atlas is a local-first personal infrastructure operating system.

## Current Release

Atlas 0.1 — Foundry

## Core Components

- Atlas Core
- Atlas Ops
- Atlas Memory
- Atlas Home
- Atlas Vision
- Atlas Voice
- Orion Assistant
- Hermes Reasoning Engine

## Principles

- Local first
- Private by design
- Modular
- Observable
- Recoverable
- Configuration stored in Git
